# 批量引物设计流程审核

审核对象：上传的 batch-primer-designer.zip；未修改原程序。以下为代码审核、运行验证和扩展建议，不代表已实现扩展功能。

## 结论

当前是可用的批量 Primer3 候选生成原型，适合用户已经准备好模板的常规 PCR 初筛。其 CLI、网页界面、输入读取和设计核心已分开，适合继续扩展。它尚不是具备参考基因组、注释解析、物种检索、脱靶验证的完整流程。

多物种支持不应理解为设置一个物种名称：需要明确参考组装版本、注释版本、目标转录本、序列来源和特异性检索范围。候选引物通过计算筛选后仍需实验验证。

## 运行证据

- 原有 unittest：8/8 通过。其中引物设计核心测试使用模拟引擎。
- 隔离 Python 3.12 环境安装 primer3-py 2.4.0 后，两个示例文件各生成 10 行成功候选。
- 固定随机种子的 800 bp 合成模板、指定目标区，真实 Primer3 返回 5 对候选；逐对核对左右结合序列、反向互补和扩增长度，均通过。
- 复现空 FASTA 标题抛 IndexError、只有表头的 CSV 返回 CLI 成功退出码、负浓度和非有限浓度通过配置校验。
- 未进行真实物种的基因组脱靶分析、NCBI 下载、实验验证或跨系统安装验证。

## 现有问题与优先级

### 高优先级

1. 缺少全基因组特异性模块。core.py:294 的 ok 只代表 Primer3 返回候选，不能解释为物种内唯一扩增。建议独立报告 design_status、specificity_status 和 reference_scope；没有执行检查时必须写 not_run，不能写 passed。
2. 缺少参考与目标语义。TemplateRecord 只有 id、sequence 和局部目标区；没有 assembly、contig、strand、gene/transcript、基因组坐标及映射关系。直接叠加基因名输入会造成同名基因、同源基因、负链、剪接异构体的歧义。
3. 测试不足以证明科研结果正确。需要增加真实 Primer3 集成测试、已知参考序列的正负链/跨外显子夹具，以及已知存在旁系同源扩增的反例。

### 可复现的程序问题

| 位置 | 问题 | 建议 |
|---|---|---|
| core.py:206 | `>` 空标题先 split()[0] 再检查空值，抛 IndexError | 先检查空标题，再取 ID；转为可定位的输入错误 |
| cli.py:76–89 | 只有表头的 CSV 产生空结果且退出码为 0 | 拒绝零记录，CLI 与 GUI 行为一致 |
| core.py:52–64 | 浓度缺少有限数、非负/合理范围检查 | 明确各参数域，拦截 NaN、Inf 和非法浓度 |
| cli.py:83–84、web_gui.py:254–260 | 按 sample_id 集合计数，重复 ID 的成功与失败集合可重叠 | 用内部 record_id 标识输入记录；分别统计记录数、有效目标数和候选对数 |
| core.py:258–265 | 仅捕获引擎调用异常；未独立保留 PRIMER_WARNING/PRIMER_ERROR | 保留原始诊断，错误与无候选分开，避免丢失重要警告 |
| core.py:287 | 反向引物坐标换算正确，但注释把右端位置称为 3′ 位置不准确 | 改正注释，并保留真实反向互补回归测试 |

补充：CLI 和 GUI 将所有记录、所有结果读入内存；网页还把完整 CSV 放入 JSON。25 MB 上传上限不限制计算时间和结果膨胀。长序列、大批量、高候选数需要队列、资源上限、进度、取消和分块下载。现有 ThreadingHTTPServer 适合本机单用户，不宜直接对外部署。

## 建议扩展能力

### 输入

| 输入 | 解析后用途 | 必须约定 |
|---|---|---|
| FASTA、FASTA.gz | 自备模板 | ID 唯一性、IUPAC 模糊碱基策略 |
| CSV/TSV/XLSX | 批量模板或目标清单 | 显式列映射、工作表、坐标体系，不执行表格公式 |
| BED | 基因组区间取序列 | 0-based 半开区间；必须绑定参考组装 |
| GFF3/GTF + FASTA | gene/transcript/exon/CDS 定位 | 1-based 闭区间、父子关系、多转录本、负链 |
| GenBank | 序列与 feature 联合导入 | compound location、join、complement |
| 基因/转录本 ID 清单 | 按注释提取目标 | 物种、组装、ID 版本；歧义需显式返回 |
| VCF（后续） | 避开变异位点、分型设计 | 参考等位基因核对、indel、样本与频率策略 |

不建议把 FASTQ 作为第一阶段直接模板输入；原始 reads 需要先完成质控、组装或比对，与模板引物设计不是同一任务。

### 实验模式

先实现常规基因组 PCR 和 RT-qPCR。RT-qPCR 需要区分跨内含子、跨外显子连接处、转录本特异与基因共同转录本设计，并检查基因组 DNA 和假基因风险。后续再增加 Sanger 验证、克隆尾序列、SNP 分型、探针和 multiplex；这些模式不宜只替换产物长度参数。多重 PCR 还需要跨引物二聚体、交叉扩增和引物池优化。跨物种保守引物需要同源序列收集、多序列比对和简并度控制，应作为独立模块。

### 输出

- CSV/TSV/XLSX：样本、目标、引物 5′→3′、长度、Tm、GC、ΔTm、罚分、状态与原因。
- JSON/JSONL：结构化候选、全部诊断、参数、版本与证据，适合继续分析。
- FASTA：引物及预测扩增子；订购表单独输出，避免把有尾序列引物的总长与退火区长度混淆。
- BED/GFF3：参考上的结合区和扩增区；剪接模板保留分段映射。
- HTML：目标结构示意、候选排序、脱靶明细、失败原因和人工复核提示。
- 热力学：发卡、自二聚体、异二聚体及计算条件；不能把不同单位和不同模型的结果混用。
- 复现清单：任务 ID、软件版本、完整参数、输入校验和、参考与注释版本、数据库索引版本、时间和运行日志。

## 本地与在线参考数据

统一使用 ReferenceBundle，手工导入与在线下载最终生成相同目录结构，例如：

```
references/<taxid>/<assembly_accession.version>/<annotation_release>/
  manifest.json
  genome.fna.gz
  annotation.gff3.gz
  transcripts.fna.gz
  indexes/
```

manifest 应记录物种学名、TaxID、assembly accession.version、数据提供者、注释版本、来源 URL、下载时间、SHA-256 和索引工具版本。不能只用物种中文名或 latest 作永久标识。

本地导入时检查 FASTA contig 与注释 seqid 是否对应、区间是否越界、父子关系与链方向是否有效；建立索引和明确的 contig 别名表。FASTA 随机访问可用 faidx/pyfaidx，注释可用 gffutils 等现有工具；普通 gzip 与支持索引的 BGZF 应区分，按工具要求建立缓存副本，不修改原始数据。

在线部分推荐采用 NCBI Datasets 检索与下载组装及可用注释，按 TaxID/学名检索候选，再确定 RefSeq/GenBank、参考/代表组装、组装级别和具体版本。E-utilities 可用于记录补充，不替代组装文件管理。并非所有组装都有注释或转录本，缺少时要明确降级能力，不能静默套用其他版本。

下载应支持清单、校验、临时目录、原子完成标志、重试退避、缓存复用和离线运行。大基因组预先检查磁盘及索引资源。遵守服务限流；若配置 API key，只从安全环境设置读取，不写入报告或仓库。当前未验证这些在线接口，实施前须核对官方现行命令与参数。

## 特异性判断

先生成比最终需求更多的候选，再用本地 BLAST+ 或经过短引物敏感性验证的比对方案寻找结合位点；之后按两引物相向、间距与错配策略枚举潜在扩增子。仅分别统计两条引物命中次数不够，通用长 reads 比对器的默认参数也不适合直接用于短引物。

报告错配位置，尤其 3′ 端错配、目标产物与脱靶产物坐标/长度，以及实际检索的数据库范围。检索应按实验需求包含核基因组、相关细胞器、替代组装或转录本；多倍体还需明确是否允许同源拷贝共同扩增。不能把“在不完整参考中未找到其他产物”称为实验特异性保证。

## 建议建设顺序

1. 修正输入和参数错误、统计语义；补真实引擎及 CLI/HTTP 集成测试。
2. 增加参考包本地导入、GFF3/GTF/BED 与基因 ID 输入、坐标映射和本地特异性分析。
3. 增加 NCBI 检索下载、离线缓存与数据版本记录。
4. 完成 JSON/XLSX/扩增子/HTML 报告和 RT-qPCR 模式。
5. 根据真实实验需求再做变异分型、跨物种保守引物和 multiplex。

建议保留现有 Python + Primer3 核心，以解析器、参考管理、目标解析、设计、验证、导出六个模块渐进扩展。直接在现有网页函数中叠加下载、解析与比对会使后续验证和维护困难。完整平台重写适合多人远程协作场景，但会增加部署和维护成本；单纯增加文件后缀则无法解决参考与特异性问题。

验收应包含至少两个注释结构不同的物种（例如细菌与真核），另有负链、多转录本、旁系同源、多倍体或细胞器的针对性样例；验证离线复现、失败可诊断、坐标可回溯和已知脱靶能被识别。实验验收另行确认扩增效率、单一产物、熔解曲线等适用指标。
